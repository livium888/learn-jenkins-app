# Scotland Trip App

Offline itinerary app for our family trip to Scotland, **18–24 Aug 2026** — Edinburgh (festival season), plus day trips to Stirling and Glasgow. Built for a family of 3 with a 4-year-old who walks (no stroller).

This is a Capacitor (HTML/CSS/JS + WebView) Android app with five tabs: Overview, Itinerary, Places, Budget, and Tips (walking pace, crowd-avoidance, safety notes, packing checklist).

## Getting the APK

Every push to this branch builds a debug APK via GitHub Actions (`.github/workflows/scotland-trip-app.yml`) and publishes it directly to this repo's **Releases** page as `app-debug.apk` — tap it on your phone to install, no GitHub login required.

## Project structure

- `www/` — the app itself (plain HTML/CSS/JS, no build step)
- `www/js/data.js` — all trip content (itinerary, places, budget, tips, packing list)
- `android/` — native Android project generated by [Capacitor](https://capacitorjs.com/)

## Building locally

```bash
npm install
npx cap sync android
cd android
./gradlew assembleDebug
# APK at android/app/build/outputs/apk/debug/app-debug.apk
```
